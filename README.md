# Kolamba Capital

Sri Lankan and global economics, finance and markets news channel, with a live TV section and KC Learn (lessons and 28-day programmes).

This is a static site. All headlines and market figures are sample content for demonstration. Stock footage from Pexels (free licence).

- `index.html`: the whole site (web and mobile app views)
- `data/learn.json`: the KC Learn library (modules, lessons, questions, glossary, programmes, programme days)
- `media/`: video clips

Learner progress is saved in each visitor's browser.
